# Air Quality at RDU Airport, 2018–2020

## Purpose
This BIOSTAT 702 project cleans daily EPA air pollution measurements from the RDU airport monitor and describes monthly patterns of CO, PM2.5, and ozone. This is an exploratory air quality analysis, not an analysis of individual sickle cell patient outcomes.

## Data source
EPA air quality monitoring data from RDU airport, Durham County, North Carolina, for 2018, 2019, and January–April 2020.

## Project files
- `data/AQ_2018.csv`, `data/AQ_2019.csv`, `data/AQ_2020.csv`: original measurements
- `R/clean_air_quality.R`: a cleaning function with an ozone unit option
- `Project2_Report.Rmd`: code, tables, plots, interpretation, and AI use statement
- `Project2_RDU_SCD.Rproj`: RStudio project file

The Word report is generated by knitting the RMarkdown file; it does not need to be stored in this repository to reproduce the analysis.

## Reproduce the report
1. Clone or download this repository and open `Project2_RDU_SCD.Rproj` in RStudio.
2. Install any missing packages:
   `install.packages(c("rmarkdown", "knitr", "dplyr", "tidyr", "ggplot2"))`
3. Open `Project2_Report.Rmd` and click **Knit to Word**, or run:
   `rmarkdown::render("Project2_Report.Rmd")`
4. This creates `Project2_Report.docx` with the R code hidden.
