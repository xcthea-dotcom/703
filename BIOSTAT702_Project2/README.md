# BIOSTAT 702 Project 2: Air Quality at RDU Airport

This project cleans daily EPA air pollution data from the RDU airport monitor and looks at CO, PM2.5, and ozone from 2018 to April 2020.

## Files
- `data/`: original CSV files for 2018, 2019, and 2020
- `R/clean_air_quality.R`: function to clean one year of data
- `Project2_Report.Rmd`: tables, plots, and written report
- `Project2_Report.docx`: Word version of the report
- `Project2_RDU_SCD.Rproj`: RStudio project file

## How to run
Open the `.Rproj` file in RStudio. Install `rmarkdown`, `knitr`, `dplyr`, `tidyr`, and `ggplot2` if needed. Open `Project2_Report.Rmd` and click **Knit to Word**. The code is hidden in the Word output.
